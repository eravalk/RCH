# RCH

Менеджер нескольких облачных аккаунтов для Windows x64. Каталог файлов и параметры приложения хранятся локально. Для доступа к облачным сервисам RCH использует rclone, для WebDAV предусмотрен отдельный клиент.

## Запуск

Распакуйте архив целиком и запустите RCH.exe. Для обновления сначала закройте предыдущую версию через меню значка в трее. Настройки прежних версий читаются из `%LOCALAPPDATA%\RoyalHub\RCHub`.

## Сборка

Установите .NET 10 SDK и выполните `./scripts/build-windows.ps1` в PowerShell. Скрипт получает rclone 1.76.0, проверяет SHA-256 архива и создаёт автономную Windows-сборку в `release/RCH-win-x64`. Для веб-просмотра нужен Microsoft Edge WebView2 Runtime.

Вход в iCloud и чтение каталога Яндекс Диска требуют проверки с реальными аккаунтами. Локальные интеграционные тесты используют тестовые каталоги.

## Журнал и обновления

Откройте «Журнал отладки» через трей или боковое меню. Отдельный файл за день находится в `%LOCALAPPDATA%\RoyalHub\RCHub\logs`. Журнал показывает этап входа и коды rclone. В окно выводятся последние 500 событий текущего запуска.

При запуске приложение проверяет последний стабильный релиз eravalk/RCH через публичный GitHub API. Кнопка в журнале запускает повторную проверку. Новый релиз открывается по кнопке в приложении. Портативный архив устанавливается вручную после выхода из RCH.

После загрузки исходников в GitHub установите новую версию в Directory.Build.props и отправьте соответствующий тег, например v0.1.10. Включённый workflow Windows release соберёт приложение и приложит ZIP к GitHub Release. Для проверки из приложения релизы должны быть доступны без авторизации.
