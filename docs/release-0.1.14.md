# RCH 0.1.14

Cloud-only images now load into a bounded preview cache and appear in visible file rows, grid tiles and the details panel. The image viewer supports zoom, dragging and previous/next image navigation. Text/source files load up to 50,000 characters for display; PDF files open in the embedded WebView2 viewer. Preview downloads do not become managed local copies. Defaults: 25 MB per preview file and 256 MB cache; configurable under Preview.

Catalog indexing publishes batches before the full walk finishes. rclone uses one streaming recursive lsjson process after the initial root listing; other providers and accounts with folder exclusions use bounded folder concurrency (default 4), without the old unconditional 125 ms pause. Failed recursive listings preserve all missing cached entries. Account refreshes use independent limited concurrency (default 2). A background timer checks due accounts every 30 seconds; each account has its own interval (default 15 minutes), manual-only mode, exclusions and cancellation. Existing adaptive backoff remains for inactive accounts. The first root listing is displayed immediately after account connection. Quota/profile refresh and local-copy downloads do not block catalog display or the next account's scan.

Local-copy jobs use a separate bounded queue, report rclone download progress and handle updated remote revisions using the configured previous-version policy (default: preserve the previous file beside the new one). Speed settings now apply per transfer, including rclone network upload/download via bwlimit. Automatic local downloads remain opt-in per account; this is not automatic bidirectional upload or cloud deletion.

Settings now include Synchronization and Preview tabs, retries for folder reads, parallelism, cache controls, conflict behavior and custom icons by extension. Account icon settings are accessible from the file toolbar. Imported icons are copied and resized into app data. Windows autostart uses the current-user Run registry key; optional download-completion notifications use Windows notification-area balloons.

Validation: core/provider checks include real rclone local remotes, transfer throttling, concurrency, incremental batches, exclusions, retries, cancellation, revision-based preview caching, cache size limits and persistence. UI checks cover early catalog visibility, cloud-only image rendering, cache reuse, image viewer, background refresh policy and existing mouse/context-menu behavior. Cloud account authentication and real-account throughput still require user verification. PDF display requires Microsoft Edge WebView2 Runtime; office formats continue to use supported local preview or the service's web interface.
